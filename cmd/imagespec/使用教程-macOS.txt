imagespec 使用教程（Mac 电脑，写给不会写程序的人看）
============================================

这份教程教你怎么在自己的 Mac 电脑上，用这个小工具检查一下"gpt-image-2"这个 AI 画图模型是
不是老老实实按规矩办事。

这个小工具是干什么的？
----------------------

你可以把 AI 画图模型想象成一个"接单画画的师傅"。官方定好了规矩，比如：

- 画多大尺寸的图是允许的，超过多大就应该拒绝接单
- 图片质量能选哪几档
- 能不能画透明背景的图
- 等等

有些提供服务的商家，可能会偷偷放宽这些规矩（比如本来不该画的超大图，居然给画出来了）。这个
小工具会按照官方定的规矩，一条一条去试，试完告诉你：这个模型到底有没有守规矩。

你不需要看懂代码，只需要跟着下面的步骤做就行。

开始之前，你需要有这两样东西
----------------------------

打开工具所在的文件夹，你应该能看到这两个文件（名字可能略有不同，但差不多是这个意思）：

1. 「imagespec」—— 这个就是工具本身（Mac 上的程序一般没有后缀名，不会写成 .exe）
2. 「config.yaml」—— 这是一张"填空表格"，你要在里面填上你的信息

如果这两个文件不在同一个文件夹里，先把它们放到一起。

另外，你还需要提前准备好两条信息（一般是给你提供 AI 服务的人或者公司给你的）：

- 一个接口地址，比如「https://token.caih.com」，或者「https://supertoken.shop」
- 一串令牌，样子大概是「sk-xxxxxxxxxxxxxxxx」这样

没有这两样东西，工具是跑不起来的，先去问要这两样东西的人拿到手。

第一步：填写"表格"
------------------

1. 用鼠标右键点一下「config.yaml」这个文件（触控板是用两个手指点一下）
2. 选择"打开方式"，再选择"文本编辑"（TextEdit，Mac 自带的软件）
3. 打开后你会看到一堆文字，其中有几行是这样的（前面带 # 的是说明文字，不用管它，也不用删）：

    base_url: https://api.openai.com
    api_key: ${OPENAI_API_KEY}

    model: gpt-image-2

4. 把 base_url: 后面的内容，换成别人给你的那个"网址"
5. 把 api_key: 后面的内容，换成别人给你的那串"密钥"
6. model: 后面保持 gpt-image-2 不要动（这就是我们要测试的模型）
7. 改完之后，按键盘上的 Command + S 保存。如果弹出一个小窗口问你要保存成什么格式，直接点
   "保留原有格式"或者带 .yaml 那个选项就行，千万别选成 .txt

小提醒：改的时候只改冒号 : 后面的内容，冒号本身和前面的字不要删，也不要多加空格、多加符号。

第二步：运行工具
----------------

Mac 上运行这类工具，需要用到一个叫"终端"（Terminal）的自带软件，黑底白字（或者白底黑字），
看起来有点吓人，但只需要打几个字就行，跟着做就好。

1. 按键盘上的 Command + 空格键，屏幕中间会出现一个搜索框
2. 输入"终端"（或者英文 Terminal），看到图标后按一下 Enter（回车），"终端"窗口就打开了
3. 接下来要让终端"走到"工具所在的文件夹。最简单的办法：在终端窗口里先输入 cd
   （注意 cd 后面有一个空格，先不要按回车）
4. 然后用鼠标把装着 imagespec 和 config.yaml 的那个文件夹，直接从 Finder 窗口"拖"到终端
   窗口里，松开鼠标，终端会自动把这个文件夹的路径帮你打好
5. 这时候按一下 Enter（回车），终端就"走到"这个文件夹里了
6. 接着输入 chmod +x imagespec，按 Enter（这一步是给这个工具"盖章"，允许它被执行，只需要
   做一次）
7. 最后输入 ./imagespec，按 Enter，工具就开始运行了

如果这时候屏幕上弹出一个提示，说"无法打开，因为无法验证开发者"或者类似的话，不用怕，这是
Mac 的安全保护机制，看下面"常见问题"里的解决办法。

第三步：等待，然后看结果
------------------------

工具跑起来之后，终端窗口里会不断刷出一行一行的文字，这是它在一条一条地测试。整个过程可能要
跑好几分钟到十几分钟不等，因为它要真的去让模型画很多张图，请耐心等它自己跑完，不要中途关闭
终端窗口。

跑完之后，注意看下面几个关键词：

- 「PASS」：这一项测试通过了，说明模型这一条规矩守住了
- 「FAIL」：这一项没通过，说明模型在这一条规矩上出了问题（比如该拒绝的没拒绝，或者该成功
  的却失败了）
- 最后还会有一个总结，大概是"一共测了多少项，通过多少项，失败多少项"

如果全都是 PASS，说明恭喜，这个模型规规矩矩，符合官方标准。

如果出现了 FAIL，先别慌，这是正常情况，恰恰说明工具发现了问题——把结果截图或者把下面这两个
文件发给懂技术的同事，让他们进一步判断：

- 同一个文件夹里，会多出一个 .json 结尾的文件，里面记录了每一项测试的详细情况
- 还会多出一个 .txt 结尾的文件，里面是这次运行时终端打印出来的所有文字记录

这两个文件名字一般是"imagespec-一串数字"，数字部分是运行的日期和时间，方便区分是哪一次跑
的结果。用 Finder 打开那个文件夹就能看到。

常见问题
--------

【提示"无法打开，因为无法验证开发者"或"来自身份不明的开发者"】
这是 Mac 自带的安全保护，遇到这个提示按下面任意一种方法处理：

- 方法一（推荐）：在 Finder 里找到 imagespec 这个文件，用鼠标右键点一下它（或者按住
  Control 键再点一下），选择"打开"，会弹出一个确认框，再点一次"打开"就行，以后就不会再
  提示了
- 方法二：打开"系统设置"（苹果菜单里能找到）→"隐私与安全性"，往下滑，能看到一条关于
  imagespec 被阻止的提示，点旁边的"仍要打开"，可能需要输入一下你的电脑密码

【终端里输入 ./imagespec 之后提示 "Permission denied"（权限不够）】
说明"第二步"里第 6 步的 chmod +x imagespec 没有执行成功，回去重新输入一次这条命令，再
运行

【终端里提示 "No such file or directory"（找不到文件）】
说明终端现在所在的文件夹不对，回去重新做"第二步"里第 3~5 步，把文件夹重新拖进终端一次

【提示"缺少 api_key"或者类似的报错】
说明"第一步"里 api_key 那一行没有填对，回去检查一下密钥有没有填、有没有多余的空格

【跑到一半卡住不动，或者提示超时】
可能是网络不好，或者对方服务器响应比较慢，多等一等；如果一直没反应，可以按 Control + C
停下来，重新跑一次

【出现一堆看不懂的英文错误】
不用一个字一个字看懂，把终端窗口里的文字截图，或者把生成的 .txt 日志文件发给懂技术的同事
看就行

【这次测试会不会花钱？】
会的。因为要真的让模型画图（包括一些比较大的图），是会产生真实费用的，这是正常现象，不是
工具出错
